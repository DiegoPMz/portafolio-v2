# 🚀 Portafolio Personal

Este portafolio está desarrollado con **Astro**, **React** y **Tailwind CSS**, integrando un stack moderno y optimizado para rendimiento, escalabilidad y presentación profesional.

---

## 🛠️ Tecnologías principales

- **Astro** `^5.18.0` → Framework rápido para sitios estáticos e híbridos.
- **React** `19.1.0` + **React DOM** → Componentes interactivos y reutilizables.
- **Tailwind CSS** `4.1.7` → Utilidades de estilo para un diseño adaptable.
- **Lucide React** `0.511.0` → Iconografía ligera y consistente.
- **TypeScript** → Tipado estático para mayor seguridad y mantenibilidad.

---

## 📦 Dependencias destacadas

- **class-variance-authority** → Gestión de variantes de componentes.
- **clsx** → Composición de clases condicionales.
- **tailwind-merge** → Fusión inteligente de clases Tailwind.
- **@astrojs/react** → Integración de React dentro de Astro.
- **@tailwindcss/vite** → Configuración optimizada de Tailwind con Vite.

---

## 🧹 Herramientas de desarrollo

- **ESLint** `9.27.0` + **Prettier** `3.5.3` → Linter y formateador para mantener código limpio.
- **eslint-plugin-astro** → Reglas específicas para proyectos Astro.
- **prettier-plugin-astro** → Formateo automático de archivos `.astro`.
- **@typescript-eslint/parser** → Soporte de TypeScript en ESLint.

---

## 📂 Estructura del proyecto

```bash
├── public/          # Recursos estáticos
├── src/
│   ├── assets/         # Imágenes, fuentes y recursos estáticos
│   ├── components/     # Componentes en React
│   ├── layouts/        # Plantillas de páginas
│   ├── data/           # Datos estáticos o JSON
│   ├── lib/            # Utilidades y funciones compartidas
│   ├── pages/          # Rutas principales
│   ├── types/          # Definiciones de TypeScript
│   └── styles/         # Configuración de Tailwind
├── astro.config.mjs    # Configuración de Astro
├── tailwind.config.js  # Configuración de Tailwind
└── tsconfig.json       # Configuración de TypeScript
